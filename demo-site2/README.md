# demo-site2（2つ目のデモサイト）

架空の社内備品貸出予約システム。1つ目のデモサイト（ECサイト）との違いは、**ログインが必要な画面**、モーダル（`<dialog>`）、iframe、
JSで描画される一覧、連番の予約ID、キャンセルの二重実行、を持つこと。過学習の防止と、ログイン後の画面の診断（Q-6/Q-7）に使う。

```bash
TEST_MODE=1 python3 demo-site2/server.py --port 8766
```
- デモ用のログイン情報（架空）: `alice@example.test` / `demo-pass-1`、`bob@example.test` / `demo-pass-2`
- 診断する場合は、`ALLOWED_HOSTS` に `127.0.0.1:8766` を追加する（サンドボックス例外の対象）。
- ドメイン所有確認は、`demo-site2/well-known/` にトークンのファイルを置くと、`/.well-known/<ファイル名>` で配信される。
