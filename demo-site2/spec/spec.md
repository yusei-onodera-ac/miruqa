# 社内備品貸出予約システム 仕様書（デモ用・架空）

対象: 社員が、ノートPC・プロジェクター・ワイヤレスマイクを予約する社内システム。
（これは、点検エージェントのデモ用に作った、架空の仕様書です。）

## 1. 認証
- SPEC-001: 予約・一覧・キャンセルなどの機能は、ログインした社員だけが使える。未ログインで開いた場合は、ログイン画面へ移動する。
- SPEC-002: ログインは、メールアドレスとパスワードで行う。誤りがあった場合は、「メールアドレスまたはパスワードが違います。」と表示する。
- SPEC-003: **パスワードを5回続けて間違えたアカウントは、15分間ログインできない**（ロックする）。

## 2. 備品の予約
- SPEC-004: 備品一覧に、備品名と在庫数を表示する。
- SPEC-005: 予約の数量は、**1点以上、備品ごとの上限（ノートPC2点、プロジェクター1点、マイク3点）まで**。範囲外の数量は、エラーとして受け付けない。
- SPEC-006: 利用日は、**今日より後の日付**を指定する。過去の日付は、受け付けない。
- SPEC-007: 在庫を超える数量は、予約できない。予約が成立すると、在庫はその数量だけ減る。
- SPEC-008: 予約の前に、確認のダイアログを表示する。確認ボタンには、何を確定するのかが分かる文言を使う（例: 「予約を確定する」）。

## 3. 予約の参照・キャンセル
- SPEC-009: 予約の詳細は、**予約した本人だけ**が見られる。他の人の予約は、表示しない。
- SPEC-010: キャンセルできるのは、**予約した本人だけ**。
- SPEC-011: キャンセルは、1つの予約について**1回だけ**有効。キャンセル済みの予約を再度キャンセルしても、在庫は増えない。

## 4. ヘルプ
- SPEC-012: ヘルプ画面に、よくある質問を表示する。文章に誤字がない。
- SPEC-013: よくある質問の中のリンクは、すべて有効なページを指す。

## 5. 表示
- SPEC-014: すべての文字は、背景と十分なコントラスト（WCAG AA相当）を持つ。
